## Featured Projects

### [CampusFind AI](https://github.com/NAYPAINGOO/CampusFind-ai)
A university lost-and-found platform for structured item reporting, discovery, matching, claims, and safer item recovery.

- Explainable matching using weighted item attributes, with optional semantic and image models.
- User dashboards, notifications, saved alerts, claims, and administrative/security tools.
- **Stack:** Next.js, React, TypeScript, Tailwind CSS, Supabase, FastAPI, Python.

### [CyberSentinel](https://github.com/NAYPAINGOO/CyberSentinel)
A local cybersecurity learning lab that turns authentication, web, and network logs into explainable alerts and investigation records.

- Log parsing, deterministic detection rules, evidence timelines, and incident notes.
- Local file collection and optional local Ollama-generated investigation drafts.
- **Stack:** Python, Flask, SQLite, Docker, Ollama (optional).
- Educational prototype; not a production SIEM or system-wide security sensor.

### [SkillSync AI](https://github.com/NAYPAINGOO/SkillSync-AI)
A career-preparation MVP for students and internship seekers.

- Text-based PDF resume review, role-based career roadmaps, internship tracking, and mock interview practice.
- Resume and interview feedback currently use transparent heuristics and curated rules; this is not a trained hiring model or an ATS assessment.
- **Stack:** React, React Router, Vite, Tailwind CSS, Flask, Python, PyPDF2.

### [CineWave](https://github.com/NAYPAINGOO/CineWave)
A responsive, multilingual movie and TV discovery interface.

- Localized catalogue browsing, discovery sections, media playback support, subtitles, and administration features.
- Designed for licensed, public-domain, administrator-owned, or otherwise officially permitted media only.
- **Stack:** Next.js, TypeScript, Tailwind CSS, Prisma, PostgreSQL, next-intl, HLS.js.

### [Hukum Linear — Interactive Mathematics Learning](https://github.com/NAYPAINGOO/hukum-linear-website)
A Malay-language learning website for Form 4 Additional Mathematics.

- Learning modules, educational games, quizzes, and a “Cikgu AI” learning assistant.
- Gemini API support with an offline fallback mode.
- **Stack:** React, Vite, Tailwind CSS, Express, Gemini API.

### [AIU Alumni Portal — Course Group Project](https://github.com/NAYPAINGOO/Project-based-Learning-Project)
A PHP-based group-project prototype whose current public homepage presents an AIU alumni community portal.

- Registration and login entry points.
- Alumni events, jobs and internships, announcements, and networking sections.
- **Stack:** PHP with web frontend assets.
- See the repository README for project scope and setup details.
